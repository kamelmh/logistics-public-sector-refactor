# Academix DSS — Screenshot Guide

## How to Take Screenshots

### Option 1: Windows Snipping Tool
1. Press `Win + Shift + S`
2. Select area
3. Save to `C:\Users\Admin\Projects\active\portfolio-site\screenshots\`

### Option 2: Print Screen
1. Press `PrtScn` to capture full screen
2. Paste in Paint
3. Crop and save
