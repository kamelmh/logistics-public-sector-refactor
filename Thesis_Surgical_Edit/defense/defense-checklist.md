## 6. الأسئلة المتوقعة — تحضير الإجابات

| السؤال | الإجابة المختصرة |
|--------|-----------------|
| لماذا اخترت VBA بدلاً من Python أو نظام قواعد بيانات؟ | النظام موجه لمستخدم Excel دون خبرة برمجية. VBA متكامل مع Excel 2010، لا يتطلب تثبيت إضافي، يعمل دون إنترنت. |
| كيف حسبت Q\* = 15؟ | Q\* = √(2DS/(I×PU)) = √(2×33×801.45/(0.20×1200)) ≈ 15 وحدة. |
| ماذا يعني ROP = 201؟ | نقطة إعادة الطلب. عندما يصل المخزون إلى 201 وحدة، يجب تقديم طلبية جديدة. |
| لماذا احتياطي الأمان 200؟ | قرار سياسي إداري — النموذج الرياضي يُعطي 2-3 وحدات فقط، لكن المديرية اختارت مخزوناً مرتفعاً لضمان عدم النفاد مهما طال التوريد. |
| هل جربت النظام على بيانات حقيقية؟ | نعم، تم تطبيقه على بيانات مديرية التربية بالبيض وتأكدت النتائج مع الحسابات اليدوية. |
| ما الفرق بين هذا النظام وExcel العادي؟ | النظام يوفر واجهة تفاعلية (UserForms)، حسابات آلية، تقارير جاهزة، ونظام إنذار عند بلوغ ROP. |
| هل يمكن تعميم النظام على مؤسسات أخرى؟ | نعم،只需 تعديل المعطيات (الطلب، المهلة، التكلفة) في جدول الإعدادات. الكود VBA لا يتغير. |
