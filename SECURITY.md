# Security Policy

## Supported Versions
| Version | Supported |
|---------|-----------|
| v13.3   | ✅ Active development |
| < v13.3 | ❌ Not supported |

## Reporting a Vulnerability
This is a student research project for the Direction de l'Education, Wilaya de El Bayadh.
If you discover a security issue:

1. **Do NOT** open a public issue — email the author directly.
2. Provide a clear description of the issue and steps to reproduce.
3. Allow 48 hours for an initial response.

## Scope
- The ERP workbook (`ERP_v13.3.xlsm`) — VBA macros and sheet protection
- CI/CD pipeline — secrets and token management
- Thesis documents — no executable content

## Out of Scope
- Submodule repositories (third-party tools)
- Python/script dependencies (pinned via requirements.txt)
